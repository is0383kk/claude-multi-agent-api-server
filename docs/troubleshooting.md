<span data-as="p">For partners integrating the Claude Agent SDK, use of Claude branding is optional. When referencing Claude in your product:</span>
<span data-as="p"><strong>Allowed:</strong></span>
<ul>
<li>“Claude Agent”, preferred for dropdown menus</li>
<li>“Claude”, when within a menu already labeled “Agents”</li>
<li>“{YourAgentName} Powered by Claude”, if you have an existing agent name</li>
</ul>
<span data-as="p"><strong>Not permitted:</strong></span>
<ul>
<li>“Claude Code” or “Claude Code Agent”</li>
<li>Claude Code-branded ASCII art or visual elements that mimic Claude Code</li>
</ul>
<span data-as="p">Your product should maintain its own branding and not appear to be Claude Code or any Anthropic product. For questions about branding compliance, contact the Anthropic <a href="https://www.anthropic.com/contact-sales" target="_blank" rel="noreferrer" class="link">sales team</a>.</span>
